## Working Files

This repository is worked on together with an AI assistant. Three files in
the repository root hold everything a session needs:

- `SESSION_BASELINE.md` - how the user and the assistant work together
- `TASKLIST.md` - the complete history of the work
- `README.md` - this file, for humans reading the repository later

`.claude.md` is the entry point. A new session starts with:
"Read <repo-root>\.claude.md". The assistant then reads the three files on
its own.
